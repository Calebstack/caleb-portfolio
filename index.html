Stack

  • PHP
  • PDO / MySQL
  • JavaScript
  • jQuery
  • AJAX
  • Bootstrap
  • Paystack API
  • SMTP

What I built

  • The complete shopping flow — product catalogue, product detail pages, AJAX-driven cart and product loading, checkout, order confirmation and a customer order-history page.

  • Customer authentication with signup, login, OTP verification and SMTP email-based password reset.
